# 用途検証 (dogfooding / 弾き戻し) の判定基準

- 確定: 2026-07-05 (第 3 期 S2 開始時、ユーザー合意済み)。**状態: fixed**
- 目的: 「粗い転写で足りる」か「精度が律速」かを**事後解釈の恣意性なしに**判定する
  (第 3 期ガードレール 14 の入力。「足りる」成立時は per-tine 実装 GO の自動再審査)
- 変更手続き: 数値・条件の変更は `docs/decision-log.md` に理由付きで追記した上で行う

## 構造: 2 本線 + 中間帯 (ヒステリシス)

判定線は「律速判定線 (R)」と「十分判定線 (A)」の 2 本で、意図的に幅を持たせる。

- n が小さく (単一奏者・曲ごとの難度差) 測定ノイズが大きいため、1 本線では判定が
  ノイズでフリップする。中間帯はシュミットトリガーとして機能する
- 2 本の線は異なる決定をゲートし、誤判定コストが非対称 (R の誤り = 精度投資を
  少し続けすぎる / A の誤り = research line 停止の誤発火)。コストが非対称なら
  閾値も非対称にする (kill 条件の hard-kill / consult 分離と同じ構造)
- 収束方針: データ蓄積に伴い中間帯は**狭める** (定義軸も体験指標側に寄せる) が、
  幅ゼロの単一境界にはしない。中間帯に落ちた回の記録が真の境界の較正データになる

## 計測項目 (dogfooding 1 回 = 自由演奏 1 本を「弾ける譜面」まで修正)

- 修正時間 (分) と音源長
- 修正操作の **7 分類カウント** (下表。生データは分類カウント、重みは較正対象)
- 「直すより諦めた」箇所数
- 音楽的曖昧性カタログ記入 (票の記入欄として副産物方式)
- 弾き戻し: **未修正譜面**でフレーズ単位の再現成功率 (別セッションで実施可)

### 修正操作の 7 分類と暫定重み

| # | 操作 | 暫定重み |
|---|------|---------|
| 1 | 偽の候補の除去 (1 タップ) | 0.5 |
| 2 | 偽の認識の除去 | 1 |
| 3 | 近接同一音のシングル/弾き直し判定 | 1 |
| 4 | 和音扱いからの一部削除 | 1.5 |
| 5 | 和音扱いへの一部追加 | 2 |
| 6 | 候補に無い onset の追加 (単音) | 3 |
| 7 | 候補に無い onset の追加 (複数音) | 3 + 追加音数 ×1 |

- 重みの由来はユーザー体感の序列 (2026-07-05)。**初回セッションの操作ログ実測
  (分類別所要時間) で較正して以降固定**する (信念でなく実測で決める — ガード
  レール 2 の精神)。較正後の変更は decision-log 追記
- 重み付きコスト率 = Σ(重み×件数) / GT 音数。**診断・改善追跡軸**であり、単独では
  判定を決めない (時間 R4/A4 がコスト差を自然に積分しているため、判定は時間・
  弾き戻し・諦めを主軸にする)
- 参考: `note_f1_benchmark.py` の costPerTruthNote (0.258 @2026-07-05) は本表の
  粗い先行版 (3 分類: 除去 1 / 候補追加 1 / 手動挿入 3)。7 分類とはスケールが
  異なるため直接比較しない

## 判定条件

「修正必要音率」= 何らかの修正を要した GT 音の割合 (操作数ではなく音数ベース)。

### 「精度が律速」 — いずれか 1 つ成立

| # | 条件 |
|---|------|
| R1 | 修正必要音率 > **0.10** |
| R2 | 「直すより諦めた」 ≥ 2 箇所 |
| R3 | 未修正譜面の弾き戻し成功率 < 60% (フレーズ単位) |
| R4 | 修正時間 > 音源長 ×5 |
| R5 | 総修正箇所 > 20 (長曲の絶対上限 — 率が低くても絶対負担で律速) |

R1 の 0.10 はユーザー体感アンカー (2026-07-05、gt-review 実作業中の申告:
「0.1 でも高く感じる、特に長い曲では」)。当初案 0.25 (機械集計の直下) は体感より
大幅に緩いと判明したため採用しない。

### 「粗い転写で足りる」 — **すべて**成立 → ガードレール 14 発火

| # | 条件 |
|---|------|
| A1 | 未修正譜面の弾き戻し成功率 ≥ 80% |
| A2 | 修正必要音率 ≤ 0.05 |
| A3 | 諦め 0 |
| A4 | 修正時間 ≤ 音源長 ×2 |
| A5 | 総修正箇所 ≤ 10 |

### 中間帯

どちらも成立しない場合は**判定保留**とし、S3 で 2 回目を実施して 2 回分で再判定する。
保留回の記録 (主観負荷・曖昧性カタログ・7 分類内訳) は境界較正データとして扱う。

## 初回の見込み (正直な予告)

現行認識器の機械集計 proxy (全録音の修正必要音率 ≈ 0.14、非飽和ではさらに高い) は
R1 を超えており、**初回判定は「精度が律速」で出る見込み**。これは第 3 期の作業仮説
(精度投資は正当) の実地確認であり、本基準の主目的は (a) A 側への接近を検知する
感度線の常設、(b) 改善が体験に反映されているかの追跡、(c) 重み較正と曖昧性
カタログの収集にある。
