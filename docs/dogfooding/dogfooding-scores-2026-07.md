# dogfooding 初見用 完成楽譜（第 2-3 回）

両曲とも 17 鍵 C メジャーカリンバで演奏可能なことを機械照合済み（外れ音なし）。
第 2 回 = 曲1 Sí Beag Sí Mór、第 3 回 = 曲2 La Mourisque。

## 記号の読み方

- リズム: `♪`=8分, `♩`=4分, `♩.`=付点4分, `𝅗𝅥`=2分, `𝅗𝅥.`=付点2分, `~`=タイ（前の音を鳴らしたまま）, `(休)`=休符
- `[上/下]` = 2音同時打ち（dyad）。上=高い音、下=低い音
- `(p)` = **弱く打つ**（弱打テスト用。普通の半分くらいの強さ）
- `:‖` = 繰り返し
- **タインの左右**（標準 17 鍵、中央=C4）: 右(R)= D4 F4 A4 C5 E5 G5 B5 D6 / 左(L)= E4 G4 B4 D5 F5 A5 C6 E6

**演奏メモ**: 初回テイクは A→B を 1 回ずつ通す（`:‖` は省略可）。慣れたら AABB。テンポは自分が確実に弾ける遅さで崩さずに。dyad は「両親指を同時に離す」意識で。**撮り直しはしない**（下記プロトコル参照）。

## 曲1: Sí Beag Sí Mór （O'Carolan 1670–1738 / PD）　★第 2 回

原調 D → C 長調へ長2度下移調。3/4、ゆっくりのワルツ（♩≒69–76 目安、テンポ自由）。

### A部
```
拾い:  C5♪ D5♪

 1: E5♩. D5♪ C5♩
 2: C5♩. D5♪ C5♩
 3: A4𝅗𝅥          G4♩
 4: [E4/C4]𝅗𝅥      G4♩        ← dyad① L=E4 / R=C4（中央寄り3度）
 5: A4♪ G4♪ A4♪ B4♪ C5♩
 6: D5𝅗𝅥          C5♪ D5♪
 7: E5𝅗𝅥          D5♩
 8: C5𝅗𝅥          E5♩
 9: [A4/C4]𝅗𝅥      D5♩        ← dyad② R=A4 / L=C4（6度）
10: G4𝅗𝅥          C5♩
11: E4𝅗𝅥          D4♩(p)      ← 弱打① 低域、そっと
12: C4𝅗𝅥          E5♩         ← C4(中央最長タイン)→E5 大跳躍
13: A4𝅗𝅥          D5♩
14: G4𝅗𝅥          C5♪ B4♪
15: C5𝅗𝅥. ~                   ← 鳴らしたまま次へ
16: [C5/C4]𝅗𝅥                 :‖  dyad③ R=C5 / L=C4（終止オクターブ）
```

### B部
```
拾い:  C5♪ D5♪

 1: E5♩. D5♪ C5♩
 2: D5♪ C5♪ D5♪ E5♪ G5♩
 3: A5𝅗𝅥          G5♩         ← 最高音 A5
 4: E5𝅗𝅥          D5♪ C5♪
 5: D5𝅗𝅥          G5♩
 6: E5𝅗𝅥          D5♩
 7: C5𝅗𝅥          A4♩
 8: A4𝅗𝅥          A4♪(p) G4♪(p)  ← 弱打② 同音A4の再打鍵→弱く下降
 9: E4𝅗𝅥          D4♩
10: C4𝅗𝅥          E5♩         ← 再び C4(中央)→E5 大跳躍
11: A4𝅗𝅥          D5♩
12: G4𝅗𝅥          G5♩
13: A5♪ G5♪ F5♪ E5♪ D5♪ C5♪  ← 下降ラン（やや密）
14: D5𝅗𝅥          C5♪ B4♪
15: C5𝅗𝅥.
16: C5𝅗𝅥                      :‖  終止
```

## 曲2: La Mourisque （Susato 出版1551 / PD）　★第 3 回

原調 C、旋律が低いため +1オクターブ。4/4（原譜 4/2 を半分の音価に読み替え済み）、快活だがゆっくりでよい。

### A部
```
 1: E5♪ F5♪ G5♩ G5♩ G5♩         ← 同音 G5 を3連打
 2: G5𝅗𝅥.        F5♩
 3: E5♩ C5♩ C5♩(p) D5♩           ← 弱打① 反復C5の2打目を弱く
 4: [B4/D4]𝅗𝅥    G4𝅗𝅥            ← dyad① L=B4 / R=D4（6度）
 5: E5♪ F5♪ G5♩ G5♩ G5♩         ← 1小節目と同じ
 6: G5𝅗𝅥.        F5♩
 7: E5♩ C5♩ C5♩ D5♩
 8: G4𝅗𝅥          [G4/C4]𝅗𝅥      :‖  同音G4→dyad② L=G4 / R=C4（5度）
```

### B部
```
 1: (♩休) E5♩ E5♩ C5♩            ← 冒頭4分休符
 2: C5♩ D5♩ E5♩ C5♩
 3: F5♩ D5♩ E5♩ C5♩
 4: C5♩ D5♩ [B4/D4]𝅗𝅥           ← dyad③ L=B4 / R=D4（6度）
 5: G4♩ E5♩ E5♩(p) C5♩           ← 弱打② 反復E5の2打目を弱く
 6: C5♩ D5♩ E5♩ C5♩
 7: F5♩ D5♩ E5♩ C5♩
 8: C5♩ D5♩ G4𝅗𝅥                 :‖  終止
```

## 弾き戻しプロトコル（記憶交絡フリー）

1. **初見・1 テイク**: 上の楽譜を見て初見でゆっくり弾き、録音（/debug/capture）。**撮り直さない** — 撮り直し＝練習＝記憶化で前提が壊れる。ミスはそのまま残す。
2. **認識**: 録音を認識にかける。
3. **1 日空ける**: その間、録音を聴き返さない・この楽譜を見ない・鼻歌でさらわない。
4. **弾き戻し**: 1 日後、**認識結果だけ**を見て（元楽譜は見ない）弾き、元の曲が再現できるか。認識の誤り箇所で「誤りのまま弾いた（＝譜面を読んでいる）」か「原曲どおり直した（＝記憶リーク）」を記録。

評価は 2 軸 —「弾き戻し vs 認識結果（描画忠実度）」と「弾き戻し vs 原曲（end-to-end）」— の乖離を記憶リーク指標にする。**認識精度そのものは実演奏の耳裁定 GT 基準**（楽譜どおりでなく、実際に弾かれた音）で測る。

## 弱点カバレッジ（評価側、奏者は意識不要）

和音 6 / 弱打 4 / 同音反復 6 / 密度 1（Sí Beag B-13）。D1 taxonomy の 4 系統すべてを 2 曲でカバー。

権利: 両曲とも PD 素旋律 + 自前移調・dyad 付加 → 編曲権リスク低、corpus 昇格可。
