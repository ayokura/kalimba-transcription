# dogfooding 測定の提示原本 (保全用)

弾き戻し測定で初見時に実際に提示した譜面ファイルを、**測定完了後に**そのまま置く
(`../usage-validation-criteria.md` 実施プロトコル手順 5)。

- 置けるのは **PD (パブリックドメイン) 確認済みの譜面のみ**。
- 再生成品ではなく提示したファイルそのものを置く (提示物の同一性が以後の再測定・
  end-to-end 裁定の基準になるため)。測定記録には保全 commit の hash を記載する。
- 測定完了前には置かない (gap 中の原譜再視認 = 記憶交絡の再導入を防ぐ)。
